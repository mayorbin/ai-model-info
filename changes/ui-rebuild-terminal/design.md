# 设计规格 · 深色数据终端

方向：**深色数据终端**（参照 Linear / Vercel 的克制暗色 + 彭博终端的数字密度）。
一句话概括取舍：**背景退后，信息前进；层级只靠背景明度与 1px 线，不靠阴影。**

沿用原项目 `docs/DESIGN.md` 最重要的一条结论：**画归画，数归数。**
不把数据编码进图形（「书架高度 = 上下文窗口」那类隐喻已被证伪），
图形只负责「这是谁」，比较交给能力条与数字。

---

## 一、设计 token

写在 `src/app/globals.css` 的 `@theme` 里。所有色值**只允许**在这份 token 里出现，
组件中不得出现字面色值（厂商品牌色除外，见 2.4）。

### 1.1 背景层级（明度递进，每级约 +3~5% 亮度）

| Token | 值 | 用途 |
|---|---|---|
| `--bg-void` | `#07080b` | 页面最底（`<html>`） |
| `--bg-base` | `#0c0e13` | 主内容区 |
| `--bg-panel` | `#11141b` | 卡片 / 面板 |
| `--bg-raised` | `#171b24` | hover 态、悬浮元素 |
| `--bg-inset` | `#0a0c10` | 内嵌槽（能力条底槽、输入框） |

### 1.2 描边与分隔

| Token | 值 | 用途 |
|---|---|---|
| `--line-faint` | `#191d26` | 极淡分隔（表格行） |
| `--line` | `#232936` | 标准边框（卡片、面板） |
| `--line-strong` | `#323a4b` | hover / 选中边框 |
| `--line-focus` | `#4d6fa8` | 焦点环 |

### 1.3 文字

| Token | 值 | 用途 | 对比度（on `--bg-base`） |
|---|---|---|---|
| `--fg` | `#e6eaf2` | 主文字 | ~14:1 |
| `--fg-muted` | `#9aa4b8` | 次要文字、说明 | ~7:1 |
| `--fg-dim` | `#6b7488` | 弱化：标签、单位、计数 | ~4.6:1 |
| `--fg-faint` | `#474f60` | 禁用态 | — |

### 1.4 语义色

| Token | 值 | 用途 |
|---|---|---|
| `--accent` | `#5b8cff` | 主操作、链接、焦点 |
| `--accent-soft` | `#1b263f` | accent 的底（chip / 选中行） |
| `--pos` | `#3fb950` | 优于 / 上新 / 数据源正常 |
| `--neg` | `#f85149` | 劣于 / 退役 / 数据源失败 |
| `--warn` | `#d29922` | 部分数据缺失 |
| `--gold` | `#e3b341` | 榜首 / 冠军 |

### 1.5 区域识别色

原项目用天蓝/朱红区分国外与国内，逻辑保留、饱和度压暗一档以适配终端底：

| Token | 值 | 区域 |
|---|---|---|
| `--west` | `#4a9fd8` | 国外 |
| `--east` | `#d4644f` | 国内 |

用法有且仅有三处：分区标题左侧 3px 竖条、分区顶部一层 0 → 24px 的极淡色晕、
能力条 hover 时的细分隔。**不用于文字、不用于大面积填充。**

### 1.6 圆角、间距、动效

```
--r-sm: 4px    /* 徽章、能力条格 */
--r-md: 6px    /* 卡片、面板 */
--r-lg: 10px   /* 大容器 */
--r-pill: 999px
```

间距基准 4px：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 48`。
动效只保留两处，均为 120ms `ease-out`：hover 边框提亮、focus ring 出现。
**不做入场动画、不做渐变光晕、不做玻璃拟态**（那是「科幻 HUD」方向，已否决）。

## 二、字体与数字

| 用途 | 字体 |
|---|---|
| 正文、说明、标题 | 系统无衬线：`-apple-system, 'PingFang SC', 'Microsoft YaHei', 'Segoe UI', sans-serif` |
| 数字、分数、价格、上下文、计数、ID | `ui-monospace, SFMono-Regular, Menlo, monospace` + `font-variant-numeric: tabular-nums` |

**像素字体与 `image-rendering: pixelated` 全部删除**，`public/fonts/` 与字体子集化脚本不再需要。

字号阶梯：`11 / 12 / 13 / 14 / 16 / 20 / 26 / 34`。
正文 14px / 行高 1.6；小标签 11px / `letter-spacing: 0.06em` / `--fg-dim`。
字重只用 `400 / 500 / 600`。

> 数字一律等宽 + `tabular-nums`：这是「终端感」的主要来源，也让跨行数字能对齐。

## 三、组件

`src/components/ui/` 下每个组件一个文件。

### 3.1 Panel
基础容器。`--bg-panel` + `1px --line` + `--r-md`，**无阴影**。
hover：边框转 `--line-strong`、底色转 `--bg-raised`。
可用 `accent` 属性在左缘加 3px 竖条（取值 `--west` / `--east` / 厂商色）。

### 3.2 StatNumber
大号读数：等宽、`--fg`、`tabular-nums`；单位/说明用 12px `--fg-dim` 紧随其后。
尺寸档 `sm(16) / md(20) / lg(26) / xl(34)`。

### 3.3 MetricBar（能力条）
替代原项目的像素方块能力条。**8 格等高块**，格宽弹性、格间 2px 间隙，
填充 `--accent`（或冠军场景用 `--gold`），空槽 = `--bg-inset` + `1px --line` 内描边。
右侧必须跟一个 `tabular-nums` 数值文本——颜色不是唯一信息载体。
格数语义与原 `aptitude.ts` 一致（0–8 档），**不改评分口径**。

### 3.4 Badge
胶囊徽章：11px、`--r-pill`、1px 边框、底色为对应语义色的 12% alpha、文字为该语义色。
语义枚举：`new` / `retired` / `self-reported` / `partial-data` / `unranked`。

### 3.5 SectionHeading
13px `600` + 标题 + 右侧等宽计数（`--fg-dim`）+ 下方 1px `--line` 全宽分隔。
分区标题额外带 `--west` / `--east` 左竖条。

### 3.6 VendorLogo

| 尺寸 | 用途 |
|---|---|
| 20px | 卡片内、榜单行内 |
| 24px | 厂商分组头 |
| 32px | 冠军格、厂商页首屏 |

- 默认**单色**（`--fg-muted`，hover 转 `--fg`）；`--color` 品牌色变体只用在分组头与冠军格。
- 映射表 `src/data/vendor-logos.ts`：`vendorId → lobe-icons slug`。
- 兜底：**单字徽章**——`--r-sm` 方块，底色为厂商品牌色 18% alpha，文字为提亮后的品牌色，
  取中文名首字（如「智」）或英文名首字母（如 `T`）。计算走 `src/lib/color.ts` 的 `readableOnDark()`。

## 四、首页布局

自上而下六段，桌面 1440 对齐 `--page-max: 1360px`，左右留白 24px。

### 4.1 Header（56px，1px 底边框）
左：站名（16px / 600）。中：搜索框占位（本次不接逻辑，做静态样式）。
右：导航项（13px，当前项 `--fg` + 底部 2px `--accent`）。

### 4.2 StatusBar（等宽 12px，一行）
`● 数据更新于 2026-10-06 · 617 模型 · 65 厂商 · 数据源 10/10`。
状态灯是 8px 圆点，颜色取 `--pos` / `--warn` / `--neg`。
模型数报**在役**（未退役）数量——它与 4.4 六个类型计数之和必须相等，
两处对不上会让读者以为哪边算错了。取代原项目那个「HUD 仪器读数」：
同样的意图，去掉像素描边与呼吸灯。

### 4.3 今日格局（冠军条）
8 格响应式网格（1440 → 8 列 / 1024 → 4 列 / 640 → 2 列）。
每格自上而下：冠军标签（11px `--fg-dim`）→ 模型名（14px `600`，可换行）→
`VendorLogo` 20px + 厂商名（12px `--fg-dim`）→ `StatNumber` lg 大数字 →
一句为什么（12px `--fg-muted`，最多两行）。
八个冠军的**口径完全沿用** `champions.ts`，不改判定规则。

### 4.4 按类型
6 个 chip 横排（文本 / 视觉 / 全模态 / 图像生成 / 视频生成 / 语音），
每个 = 类型名 + 等宽计数。整体作为带 1px 边框的单行容器，chip 之间 1px 竖分隔。

### 4.5 广场
两个 Section（国外 / 国内）上下堆叠，各自整行铺满。

**区内先按三档分段**（头部 / 主力 / 尚无评测，分组依据见 `roster.ts`），
每段一行细标签 + 一条横线 + 该档厂商数。这条路牌必须留着：原项目的 DESIGN.md
反复强调读者要回答两个问题——「哪里的」和「多强」。少了它，一个毫无评测成绩的
社区微调者会和 OpenAI 在视觉上平起平坐。

段内按厂商分组：

- **组头**：`VendorLogo` 24px + 厂商名（14px `600`）。
- **组体**：模型卡片网格，`repeat(auto-fill, minmax(240px, 1fr))`，间距 12px。
  每家厂商默认只出当家门面这一张卡片。
- **组尾**：可选的「本家更新」小注（`Badge` + 型号名，整行可截断，完整说明在 `title`）。

**模型卡片**（`ModelCard`，替代原 `ModelRoom`）：
1. 顶部：`VendorLogo` 20px + 模型名（14px `600`）+ 状态 Badge（至多一个）
2. 中部：四条能力条，标签 11px `--fg-dim` + `MetricBar` + 等宽数值
   —— 聪明 / 编程 / 记性 / 便宜，口径沿用 `aptitude.ts`。
   自报成绩在数值后追加「自报」后缀，完整出处留在悬停提示里。
3. 底部：一行事实（12px `--fg-dim`，可截断）——厂商 · 发布日期 · 开源/闭源。
   价格与上下文已作为「便宜」「记性」两条能力条的短标出现在中部，不再重复；
   原先设想的「一句定位」来自 `persona.ts`，该模块未移植，本次不重新生成人设文案。

密度目标：1440 下一屏 **≥ 12 张卡片**（原项目为 6 间屋子）。

### 4.6 Footer
1px 上边框，两行：左为站内链接，右为数据来源与许可说明（复用 `credits` 页文案与 `outbound()` 链接安全门）。

## 五、可访问性与自查清单

- 正文对比度 ≥ 7:1，`--fg-dim` 用到的位置 ≥ 4.5:1。
- 焦点环：2px `--accent` + 2px offset，**必须可见**，不得 `outline: none`。
- `MetricBar` 与所有状态色都附带文本，颜色不得是唯一信息载体。
- `VendorLogo` 无有效 logo 时必须渲染兜底单字徽章并带 `aria-label`，不得渲染空元素。
- 断点自查：1440 与 390 两档截图，确认无横向滚动、无文字截断、卡片不塌陷。
