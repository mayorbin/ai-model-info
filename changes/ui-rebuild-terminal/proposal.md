# 变更提案

## 背景（Why）

现有 `D:\Study\source_code\ai-model-world` 整站是「像素小镇」隐喻：每个模型是一个 64×64 的
chibi 小人，每家厂商是一间像素小屋，家徽是 12×12 的字符画（`src/data/crests.ts`），
全站深蓝灰底 + 中文像素字体 + 零圆角。这套视觉的维护成本集中在三条链路上——
精灵图管线、像素字体子集化、家徽字符画——它们只服务于「游戏感」，
不承载任何数据。

新项目 `ai-model-info` 要保留原项目的**数据与逻辑**（快照、评分、榜单、搜索、家徽之外的一切
派生规则），但把视觉层整体换成**深色数据终端**风格：近黑底、1px 细线、等宽数字，
厂商身份由**官方品牌 logo** 表达而不是像素小人。这样做的直接收益是：
去掉整条精灵图/像素字体管线，删掉一类「隐喻需要解码」的阅读成本，
并把厂商识别交给读者本来就认得的商标。

## 变更内容（What Changes）

- 新建独立项目 `ai-model-info`，不复用原项目的 UI 组件树（`components/{character,world,room,leaderboard,compare}` 全部重写）。
- 数据层与派生逻辑从原项目移植，其中 `src/lib/derive.ts` 必须拆分：保留评分半区，丢弃角色视觉半区。
- 厂商识别从像素家徽换成官方 logo：以 `@lobehub/icons-static-svg`（MIT、零依赖、950 图标、带 `-color` 品牌色变体）为主，覆盖约 37/45 家。
- 未收录厂商按官网核实官方 logo 后自托管；确实拿不到的退化为「单字徽章」（首字母/单字 + 品牌色底）。
- 新增深色终端设计系统：设计 token、原子组件（Panel / Badge / StatNumber / MetricBar / SectionHeading / VendorLogo）。
- 本次只交付**设计系统 + 首页广场样板**，其余路由（模型详情、时间线、排行榜、全部模型、对比、厂商页、致谢）不在本次范围。

### 保留什么 / 改变什么

| 维度 | 保留 | 改变 |
|---|---|---|
| 数据来源与同步管线 | 完全保留（`scripts/sync`、`data/models.json`） | 本次不重跑管线，直接移植现有快照 |
| 评分 / 榜单 / 搜索逻辑 | 保留 | 剥离其中的角色化文案与视觉编码 |
| 「今日格局」「按类型」「国外/国内」「厂商分组」信息结构 | 保留 | 重新排版为终端仪表风格 |
| 模型形象 | — | 删除精灵小人，改由官方 logo + 能力条表达 |
| 像素字体 / 零圆角 / 像素描边 | — | 删除，改为系统无衬线 + 等宽数字 + 小圆角 |

## 范围（Scope）

### 范围内（In Scope）

- `ai-model-info` 工程脚手架与构建配置。
- 纯数据层与派生逻辑的移植（含 `derive.ts` 拆分）。
- 深色终端设计 token 与基础原子组件。
- `VendorLogo` 组件、lobe-icons 映射表、8 家未收录厂商的官方 logo 补齐与兜底。
- 首页广场完整重做（Header/状态行、今日格局、按类型、厂商分组广场、Footer）。
- 构建通过 + 1440/390 两个断点的截图自查。

### 范围外（Out of Scope）

- 模型详情页、时间线、排行榜、全部模型、对比页、厂商页、致谢页。
- 搜索框与 `public/search-index.json` 构建步骤（首页样板阶段先不接）。
- B 站 Toy 打包部署链路（`NEXT_BASE_PATH` / `scripts/toy`）。
- 重新运行 `npm run sync` 抓取新数据。
- 原项目 `ai-model-world` 的任何修改（保持原样以便对照）。

## 影响与验证

- **影响区域**：新目录 `D:\Study\test\ai-model-info`；不改动原项目。新增运行时依赖仅 `@lobehub/icons-static-svg`（其 SVG 会被复制进项目自托管，构建期不再依赖该包）。
- **完成证明**：
  1. `npx tsc --noEmit` 与 `npx eslint src` 通过；
  2. `npm run build`（静态导出）成功产出 `out/`；
  3. 首页在 1440px 与 390px 两个断点的 Playwright 截图，确认无横向溢出、字号可读、厂商 logo 正确显示且未收录厂商有可见兜底徽章；
  4. 首页渲染的模型数与厂商数与 `data/models.json` 一致。
